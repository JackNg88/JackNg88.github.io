# AGENTS.md

Guidance for coding agents working in this repository.

## Repository overview
- Static GitHub Pages personal site (`jianwu-atlas.github.io`).
- Main pages are root-level `.html` files (e.g., `index.html`, `publications.html`, `tutorials.html`).
- Shared assets are in `assets/`:
  - Styles: `assets/css/style.css`
  - Rendering/runtime JS: `assets/js/main.js`, `assets/js/render.js`
  - Data-driven content: `assets/js/data/*.js`
- Tutorial source markdown lives in `tutorials-src/`; generated tutorial pages live in `tutorials/`.

## Build and validation
- Install Python dependencies:
  - `python3 -m pip install -r requirements.txt`
- Build tutorials from markdown:
  - `python3 scripts/build_tutorials.py`

## Important generation rules
- `assets/js/data/tutorials.js` is auto-generated by `scripts/build_tutorials.py`; do not edit it manually.
- When editing `tutorials-src/*.md`, regenerate outputs so `tutorials/*.html` and `assets/js/data/tutorials.js` stay in sync.
- Files in `tutorials-src/` that start with `_` are templates and are skipped by the build script.

## Change scope expectations
- Keep changes minimal and targeted to the requested task.
- Do not refactor unrelated HTML/JS/CSS while handling a focused request.
- Preserve existing bilingual (Chinese/English) content style where applicable.
