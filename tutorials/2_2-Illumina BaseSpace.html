scRNA-seq Analysis Using Illumina DRAGEN Pipeline¶{.anchor-link} {#scRNA-seq-Analysis-Using-Illumina-DRAGEN-Pipeline}

  1. Make account on illumina basespace:\ https://login.illumina.com/platform-services-manager/?rURL=https://basespace.illumina.com&clientId=basespace&clientVars=aHR0cDovL2Jhc2VzcGFjZS5pbGx1bWluYS5jb20vZGFzaGJvYXJk&redirectMethod=GET#/register
  2. Here, we can create different projects. Within a specific project, we can upload files either by drag-and-drop or using the CLI.
  3. To run a specific app, go to the Apps tab and type "single cell". This will display the DRAGEN Single Cell RNA app. Click on it to open this app, where you can view pipeline information, input file requirements, and other relevant details. Then click Launch Application, select the required input files and parameters, and run the analysis.

Install BaseSpace Sequence Hub CLI¶{.anchor-link} {#Install-BaseSpace-Sequence-Hub-CLI}

documents: https://developer.basespace.illumina.com/docs/content/documentation/cli/cli-overview\ Installation for Linux given below:

Installation for Linux¶{.anchor-link} {#Installation-for-Linux}

::: highlight # make directory :::

::: highlight $ mkdir -p $HOME/bin $ wget "https://launch.basespace.illumina.com/CLI/latest/amd64-linux/bs" -O $HOME/bin/bs :::

::: highlight # file permissions :::

::: highlight $ chmod u+x $HOME/bin/bs :::

Authenticate to EU server¶{.anchor-link} {#Authenticate-to-EU-server}

::: highlight bs auth --api-server https://api.euc1.sh.basespace.illumina.com :::

You will get a URL and paste it into a browser

Inspect the token¶{.anchor-link} {#Inspect-the-token}

::: highlight $ bs whoami :::

To configure the server to EU¶{.anchor-link} {#To-configure-the-server-to-EU}

::: highlight $ eval $(bs load config eu) :::

::: highlight # To get list of projects :::

::: highlight $ bs list projects :::

::: highlight # To get list app session :::

::: highlight $ bs list appsession :::
