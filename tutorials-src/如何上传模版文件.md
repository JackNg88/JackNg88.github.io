## 📝 字段说明（每次新建教程时需要填的内容）

```yaml
---
title: "Ep.XX — 标题"      # 必填。会显示在页面 <h1>、浏览器标题栏、tutorials.html 列表卡片
date: 2025-11-20            # 必填。格式必须是 YYYY-MM-DD（不加引号也可以，YAML 会自动识别成日期）
summary: "一句话摘要"        # 必填。显示在列表卡片和 <meta name="description">，建议控制在 100-160 字符
type: tutorial               # 必填。目前只有两种取值：tutorial（教程）或 podcast（播客）
tags: ["R", "Seurat"]         # 可选，默认为空数组 []。会渲染成页面顶部和卡片上的标签
cover: ""                     # 可选，默认空字符串。如果以后想给卡片配封面图，填相对路径，例如 "assets/img/tutorials/ep02-cover.png"
---
```

## 🚀 新增一篇教程的完整操作流程

1. **复制模板**，在 `tutorials-src/` 目录下新建文件，**文件名就是这篇教程的 URL slug**，例如：

   ```
   tutorials-src/ep02-trajectory-analysis.md
   ```

   生成后对应的页面地址就是 `tutorials/ep02-trajectory-analysis.html`。

2. **修改 front matter 和正文内容**（参考上面的模板）。

3. **本地跑一次构建脚本**（确认没有报错）：

   ```bash
   python3 scripts/build_tutorials.py
   ```

   正常情况下你会看到类似输出：

   ```
   ============================================================
   开始构建 Tutorials & Podcast 页面...
   ============================================================
   [ok]  生成页面: tutorials/ep00-podcast-intro.html
   [ok]  生成页面: tutorials/ep01-scrna-pipeline.html
   [ok]  生成页面: tutorials/ep02-trajectory-analysis.html
   [ok]  已全量重建: assets/js/data/tutorials.js（共 3 条）
   [ok]  tutorials.js 通过 node --check 语法自检
   ============================================================
   构建完成 ✅  共发布 3 篇教程/播客

      - [2025-01-01] Ep.01 — Building an scRNA-seq Analysis Pipeline...
      - [2025-01-01] Ep.00 — Podcast Introduction & Roadmap

   ```

4. **提交并推送**这几个改动到 GitHub：
   - `tutorials-src/ep02-xxx.md`（你的源文件，仅供你自己维护，可选是否推送到公开仓库）
   - `tutorials/ep02-xxx.html`（自动生成的静态页面）
   - `assets/js/data/tutorials.js`（自动全量重建）

## 🔧 一个小优化：自动跳过 `_` 开头的模板文件

如果你想把 `_template.md` 放在 `tutorials-src/` 里当模板长期保留、但不被脚本误当成正式教程发布，只需要在 `build_all_tutorials()` 里加一行过滤：

```python
    md_files = sorted(TUTORIALS_SRC_DIR.glob("*.md"))
    # 跳过以下划线开头的文件（约定作为模板/草稿，不参与发布）
    md_files = [f for f in md_files if not f.stem.startswith("_")]
```

把这一行加在原脚本 `build_all_tutorials()` 函数里 `md_files = sorted(...)` 那一行的正下方即可，其他都不用动。
